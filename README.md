# Tabungan Qurban Mobile Platform

A mobile-first digital platform for managing sacrificial livestock savings (Tabungan Qurban), tracking installments, and coordinating distribution schedules.

## Overview

Tabungan Qurban streamlines community livestock participation through structured savings targets. Designed with mobile-first usability in mind, the platform allows participants to monitor accumulated balances and projected targets with clarity.

## Key Capabilities

- **Savings Plan Tracker**: Set monthly target plans and monitor accumulated progress.
- **Transaction History**: Real-time logging of installment payments and balance verification.
- **Mobile-First Experience**: Fluid touch-oriented layout optimized for smartphone screens.
- **High-Performance Architecture**: Rapid hot module replacement and bundle optimization via Vite and Tailwind CSS.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/ndiecyber/TabunganQurban.git
cd TabunganQurban

# Install dependencies
npm install

# Start local development server
npm run dev
```
